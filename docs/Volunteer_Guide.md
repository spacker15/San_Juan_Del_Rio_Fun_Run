# Saints Run Wild: How to Use the Spreadsheet

## Setup (once)
1. **Students** tab: paste Student name, Teacher, Grade (one row per student). Use the same spelling OneCause uses.
2. **By Teacher** tab: type each teacher's name once in the sand cells (same spelling as on Students). Check the Goal.
3. **Daily Challenges** tab: dates and targets are already filled from the flyer. Change them only if the schedule changes.

## Every day
1. **Donations** tab: add new gifts at the bottom.
   - **OneCause:** copy the Date, Participant Name, Donor Name, and Amount columns from the export. Paste them into columns A–D, then type `OneCause` in Method.
   - **Cash/check:** type the date, student, donor, amount, and `Cash` or `Check`.
2. **Red rows** on Donations mean the student name isn't on the Students list. Fix the spelling (or add the student).
3. Look at the dashboards: **By Teacher**, **By Day**, **Daily Challenges**.

Wild Card Wednesday: on Students, filter the "$ 11/4" column for amounts above $0, then draw 10 names.
